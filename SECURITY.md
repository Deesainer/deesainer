# Security policy

Please report vulnerabilities privately: open a GitHub security advisory on this repository (Security > Report a vulnerability) rather than a public issue. Include the version (`deesainer-cli --version`), the input that triggers the problem and what you observed.

We aim to acknowledge reports within a week. Fixes land with a regression test and are mentioned in the release notes once a release containing them is out.

What we consider in scope, and what we explicitly do not protect, is written down in docs/security/threat-model.md.
