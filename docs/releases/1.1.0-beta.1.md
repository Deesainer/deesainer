# Deesainer 1.1.0 beta 1

The first public release of Deesainer: an open-source interface design tool written in Rust, for macOS, Windows, Linux and the browser. It is a beta: the feature set is broad and tested, but it has not yet been through long daily use by many designers. Expect rough edges, and please report them.

## What you can do with it

- **Design** on an infinite canvas: frames, shapes, the pen with vector networks, boolean operations, text with real shaping (OpenType features, variable fonts, lists), multiple fills, gradients, images with adjustments, strokes per side, shadows and blurs, masks and blend modes.
- **Lay out** with constraints, auto layout (rows, columns, grids, wrap, min and max sizes) and layout guides.
- **Build systems** with components, variants, properties, slots, styles, and variables with collections and modes; share them through library files with a review step before updating.
- **Prototype** with interactions, transitions, scrolling, variables and conditionals, and play them in the Present window.
- **Hand off** with an Inspect tab (spacing, CSS, SwiftUI, Compose) and exports to PNG, JPEG, WebP, SVG and PDF.
- **Work together** live: cursors and cursor chat, comments, version history with a visual comparison, branches with a visual merge review.
- **Bring existing work**: open `.fig` files and SVGs, or import through the Figma REST API with your own token; missing fonts are listed and can be replaced in one step.
- **Automate** everything: every feature is a documented command, available from the CLI, an MCP server, a local control protocol and WebAssembly plugins.

## Team server (preview)

`deesainer-server` keeps a team's files on a server you run: invite-only accounts, per-file roles (editor, commenter, viewer) applied to open sessions at once, and an HTTP API. The desktop app signs in, opens and uploads files from File ▸ Collaborate…. Start it with `deesainer-server --data DIR`; `deesainer-server` without arguments prints its options.

## Cloud (planned)

| Linux (x86_64) | `.deb` or `.tar.gz` | |
| Command line | `Deesainer-1.1.0-beta.1-macos-cli.zip`, and inside the other packages | `deesainer-cli`, `deesainer-relay`, `deesainer-server` |

`SHA256SUMS.txt` lists the checksum of every file.

## Known limits

- Plain paragraphs in a text layer that also has a list wrap at the list's indent.
- A variable font's width axis does not change line breaks or the editing caret.
- `.fig` import does not bring prototype links or number, text and boolean variables yet.
- The browser build draws text only with fonts listed in its `fonts/index.json`.
