# Deesainer 1.1.0 beta 5

The AI assistant grows up: replies stream in with tokens and timing per
request, a Plan mode proposes a plan before anything changes and Execute
plan carries it out, replies render as Markdown with colour swatches, and
prompts and the last conversation survive a restart. Recolouring is one
step: `color.list` shows a page's palette and `color.replace` swaps it, with
separate maps for fills, strokes, shadows and text, so a light design turns
dark in one call. Batches can chain the ids their earlier steps return,
shapes take a corner radius when created, colour parameters take hex
everywhere, and the MCP layer tree and command list are much smaller.
