# Deesainer 1.1.0 beta 4

The canvas now matches the reference tool's colours on wide-gamut Mac
displays: when the screen uses the Display P3 primaries, the presentation
layer converts from sRGB at draw time while every export stays sRGB. On
Windows the app no longer opens a console window next to its own, Figma
import maps the GLASS effect to a background blur, and the file name menu
offers SVG and Figma import.
