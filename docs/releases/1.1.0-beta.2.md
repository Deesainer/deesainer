# Deesainer 1.1.0 beta 2

The second beta. It is the same broad, measured feature set as beta 1, with the interface in seven languages, an installer for Windows and an MCP flow that edits the open app live.

## What changed since beta 1

- **Interface languages**: the whole chrome — menus, palette, sidebars, the layers and pages panels, the design panel, the Inspect tab, components and auto layout, assets, comments, version history and design checks — is now available in English, Italian, Spanish, French, German, Simplified Chinese and Japanese. Switch live from View ▸ Language; the choice is remembered. Chinese and Japanese load a CJK-capable system font. The engine, the commands and the docs stay in English.
- **MCP edits the open app**: `deesainer-cli mcp` now bridges into a running Deesainer automatically, so an agent's commands appear on the canvas as they happen; `--standalone` keeps the headless document. The server also tells the agent which document the app has open, so it asks before replacing your work.
- **Windows installer**: a proper NSIS installer (`Deesainer-…-windows-x64.exe`) with an uninstaller and file associations, alongside the portable zip.
- **Linux package**: the `.deb` now declares its runtime dependencies (the GUI no longer needs a manual `libxkbcommon-x11` install), and the release pipeline smoke-tests the installed package headlessly — the CLI, the GUI over the control protocol, the relay and the team server.
- **Fixes**: the Windows plugin tests no longer crash (wasmi is built unoptimised in dev builds); the licence table is platform-stable; the checksums file no longer contains its own hash; the Windows executables embed the app icon.

## Team server (preview)

`deesainer-server` keeps a team's files on a server you run: invite-only accounts, per-file roles (editor, commenter, viewer) applied to open sessions at once, and an HTTP API. The desktop app signs in, opens and uploads files from File ▸ Collaborate…. Start it with `deesainer-server --data DIR`; `deesainer-server` without arguments prints its options.
